# Optics Lab Assistant

대화형 광학 실험·장비 이상 점검 도우미입니다. 가상 실험의 조건을 조절하고, 관련 이론과 MCP 계산 결과를 바탕으로 AI에게 질문할 수 있습니다.

**[프로젝트 소개 · 아키텍처 · 실행 방법 →](doc/README.md)**

- Vue 3 기반 광학 실험·장비 시뮬레이션
- LangGraph 에이전트와 MCP 문서 조회·공식 계산
- FastAPI REST/SSE 채팅, Markdown·LaTeX 표시
