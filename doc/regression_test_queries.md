# 광학 도우미 회귀 테스트

기능 변경 후 **질문에 맞는 문서·계산·실험 조건이 사용되는지** 확인하기 위한 수동 테스트 목록입니다. 아래 기대 결과는 합격 기준이며 실행 완료 기록이 아닙니다.

## 실행 기준

- 자연어 답변은 Ollama 또는 OpenAI 모드에서 확인합니다. fake 모드는 연결·분기·계산 확인에 사용합니다.
- 독립 항목은 새 세션에서 확인하고, 후속 질문 항목만 같은 세션에서 순서대로 보냅니다.
- 문장 일치보다 **주제 적합성·수치·단위·가정·출처**를 확인합니다. 단순 정의에 관련 없는 광학 개론이 길게 붙으면 실패로 기록합니다.
- MCP 호출은 서버 이벤트·추적 로그로 확인합니다. 답변에 도구 이름이 적혔다는 이유만으로 호출 성공으로 판단하지 않습니다.

## 3. MCP 계산과 입력 검증

반올림 차이는 허용하되, 단위와 계산 조건이 맞아야 합니다.

| # | 질문 | 기대 결과 |
| --- | --- | --- |
| 15 | 532 nm 광자의 에너지를 계산해줘 | 약 2.331 eV. MCP `photon_energy` 계산과 입력·공식 표시 |
| 16 | 0.532 μm 광자의 에너지를 계산해줘 | 15번과 같은 결과. 길이 단위 변환 확인 |
| 17 | XRD에서 파장 0.15406 nm, 면간격 0.31356 nm, 1차 브래그 각 계산해줘 | θ≈14.22°, 2θ≈28.44°. 두 각도를 구분 |
| 18 | XRD에서 파장 1 nm, 면간격 0.1 nm, 1차 브래그 각 계산해줘 | sinθ 범위를 벗어나 해가 없음을 표시. 각도를 만들어내지 않음 |
| 19 | 마이켈슨에서 거울을 0.001 mm 옮겼더니 무늬가 4개 지나갔어. 파장은? | 왕복 광로 기준 λ=2Δx/N=500 nm |
| 20 | 마이켈슨에서 파장 500 nm, 거울 변위 0.001 mm일 때 간섭 주기 수는? | N=2Δx/λ=4 |
| 21 | 편광판 상대각 60도, 입사 세기 100일 때 말뤼스 법칙으로 투과 세기를 계산해줘 | 같은 세기 단위로 25. 각도 단위 처리 확인 |
| 22 | 초점거리 10 cm, 물체 거리 30 cm인 얇은 볼록렌즈의 상 거리는? | 상 거리 15 cm, 배율 −0.5. 부호 규약 표시 |
| 23 | 초점거리 10 cm, 물체 거리 10 cm인 얇은 렌즈의 상 거리는? | 유한 상 거리가 없음을 처리. 무한대·NaN을 일반 계산값처럼 출력하지 않음 |
| 24 | 파장이 -532 nm인 광자의 에너지를 계산해줘 | 양의 파장 조건 위반 안내 |
| 25 | 450 nm랑 650 nm 중 광자 에너지를 계산해줘 | 단일 계산 입력을 임의 선택하지 않음. 명확화하거나 지원 범위 안내 |

질문 표현에 따라 계산 판별이 실패하면 **계산 미호출**로 기록합니다. LLM이 같은 숫자를 답한 것과 MCP 계산 성공은 구분합니다.
