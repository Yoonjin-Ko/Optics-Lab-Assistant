# 공개 파일 개인정보·비밀정보 점검

점검일: 2026-10-22

## 정리한 내용

- 보고서 본문을 루트 [README](../README.md)에 통합하고 중복 Markdown·HTML 보고서를 제거했다.
- 공개 README·발표 목차·비교 화면 HTML에서 작성자 이름·교육생 번호를 제외했다. 제출 양식에서 요구하면 공개 저장소와 분리한 제출본에 기재한다.
- 비교 기록 캡처의 머리글에도 식별 표기가 있어, 익명화한 HTML을 실제 브라우저에서 다시 촬영해 교체했다. 원답·시간·판정은 바꾸지 않았다.
- `.DS_Store`와 대화 DB의 WAL·SHM 등 보조 파일을 `.gitignore`에 추가했다.

## 확인 결과

| 항목 | 확인 범위와 결과 |
| --- | --- |
| 개인 식별 텍스트 | Git 추적 파일 및 무시되지 않은 새 텍스트 파일에서 기존 작성자 이름·계정 표기·교육생 번호·로컬 사용자 절대 경로 재검색. 해당 표기 없음 |
| API 키·토큰·개인키 | 대표 서비스 키 패턴·개인키 헤더 검사에서 실제 키 발견 없음. 로컬 환경 파일의 비밀 값과 공개 대상 텍스트를 직접 비교해 동일 값의 복사본도 찾지 못함 |
| 환경 파일·대화 DB | `.env`와 `session.db`는 Git 무시 대상. 현재 추적 파일과 과거 파일 변경 기록에도 두 파일은 없음. `.env.example`은 샘플로 유지 |
| Git 과거 diff | 현재 로컬에서 접근 가능한 모든 브랜치·태그의 추가된 텍스트를 키 패턴으로 검사. 해당 패턴 발견 없음 |
| 이메일 형태 | 검색 URL 경계 테스트의 가상 호스트 표기가 탐지됐으나 개인 이메일은 아님. 테스트 유지 |
| 이미지 | 보고서 비교 캡처의 식별 머리글 교체. 보고서 JPEG의 EXIF 메타데이터 없음. 프로젝트 캡처 외 임의 이미지 전체의 OCR 검증을 수행한 것은 아님 |
| Git 메타데이터 | 커밋 작성자 이메일이 존재함. 파일의 개인정보 제거와 별개이며, 과거 커밋·계정 설정은 변경하지 않음 |

이 점검은 패턴 검색과 알려진 환경 비밀 값의 일치 검사이다. 모든 종류의 개인정보·비밀정보가 절대로 없다는 보증은 아니다. 무시된 `.env`와 DB는 로컬에서 그대로 유지했으며 값이나 대화 내용을 보고서에 출력하지 않았다. 원격 저장소·다른 백업·삭제된 원격 브랜치까지 확인한 결과는 아니다. Git 기록을 강제로 다시 쓰거나 원격 저장소에 푸시하지 않았다.
