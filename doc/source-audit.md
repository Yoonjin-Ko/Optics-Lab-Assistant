# 학습 자료 출처 점검

확인일: **2026-10-21**. 학습 문서 18개에 근거 자료 38건을 연결했습니다. URL·해당 절·표·확인 범위는 [레지스트리](../data/source_registry.json), 요약은 각 문서 하단에서 볼 수 있습니다.

## 이번에 바꾼 내용

- 교재 전체 링크 대신 공식이 있는 절, 수치가 있는 표·초록을 연결했습니다.
- 잘못된 OpenStax 단일슬릿 URL과 관련 없는 CERN 링크를 교체했습니다.
- Si·Ge 격자상수는 값을 확인할 수 있는 논문 공개 초록, Al은 공개 논문 Table 2로 연결했습니다. Cu는 논문이 인용한 순수 구리 기준값임을 구분했습니다.
- Si·GaAs·SiO₂ 밴드갭은 논문의 **300 K 시뮬레이션 입력값**입니다. GaN은 초록의 육방정 비교값, 금속 일함수는 OpenStax 표의 대표값입니다. 인증 표준값이나 앱에서 측정한 값으로 설명하지 않습니다.
- 현미경 분해능·무한 보정 구성, 노광 해상도·초점심도, 불확도 전파에는 해당 내용을 직접 설명하는 자료를 추가했습니다.
- AI에 전달하는 문서를 발췌할 때도 출처 표를 유지합니다.

## 확인 수준

`content_checked`는 해당 설명·공식·표의 공개 본문을, `abstract_checked`는 공개 초록을 확인한 경우입니다. MIT OCW는 강의 자료 목록만 확인했으므로 `index_checked`로 구분합니다. 접근 범위 밖의 본문을 읽었다고 표시하지 않습니다.

원문 전체·영상·이미지를 복제한 데이터셋은 만들지 않았습니다. 확인한 사실을 자체 요약하고 원문 위치를 남겼습니다. 모든 문장과 시뮬레이션을 전수 물리 검증했다는 뜻은 아닙니다.

## 모델과 문헌값의 구분

문헌 수치는 입력 프리셋으로 사용합니다. 가상 실험의 선·색·움직임, 단순화한 세기 곡선, 점검 순서와 예시는 앱에서 만든 학습 모델입니다. 출처 기관의 실측 데이터나 장비 제조사의 유지보수 매뉴얼로 취급하지 않습니다. 특히 XRD의 이론 반사 위치를 실제 측정 강도 데이터로 해석하지 않습니다.

새 자료를 추가할 때는 레지스트리에 URL·근거 위치·뒷받침하는 주장·접근 범위·확인일을 기록하고 해당 문서의 출처 표도 함께 수정합니다.

## 웹 검색 출처 범위

기존 과학검증봇 노트북의 허용 출처를 대조해 ACS·RSC·PNAS·Oxford Academic·NOAA를 추가했습니다. 의학 전용 출처와 `ac.uk` 같은 넓은 접미사는 옮기지 않았습니다. 설정은 `data/search_domains.json`에서 관리하며, 검색 요청과 응답 URL 검사에 같은 목록을 사용합니다. 출처 목록에 있다는 이유만으로 검색 내용을 검증 완료로 취급하지 않습니다.
