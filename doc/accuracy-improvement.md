# 응답 정확도 개선 기록

현재 로컬 Qwen3:8B는 형식 검사를 통과해도 물리적 오답을 낼 수 있다. 병렬 호출은 지연시간 개선이며 정확도 보장은 아니다.

## 이번 변경과 확인

- 실험 스냅샷에 붙어 있던 설명 요청을 제거하고, 현재 설정·이론값과 계산 입력을 구분했다.
- 목표값을 현재값에서 복사하지 않도록 작성 요청을 정리했다. 사용자 질문은 마지막에 한 번 전달한다.
- 단위 테스트 32건 통과. 이는 물리 응답 정확도의 합격률이 아니다.
- 기존과 같은 실제 탐구 질문 5건을 로컬 Qwen3:8B와 MCP로 재실행했다. 수동 검토 결과 2건 통과, 3건 실패했다. 프롬프트 정리만으로 정확도가 개선되었다고 결론 낼 수 없다.

| 질문 범위 | 결과 | 남은 문제 |
| --- | --- | --- |
| 같은 크기의 실상 | 실패 | u=v=2f 대신 f=u로 답함 |
| 오목렌즈 허상 위치 | 실패 | 물체 쪽 허상을 렌즈 뒤로 설명 |
| 브루스터 각 | 통과 | 주어진 굴절률과 계산 일치 |
| Si의 내부 들뜸과 방출 | 통과 | 현상 구분 가능 |
| F수와 회절 | 실패 | F수 증가 시 회절 무늬 크기의 증감 반대 |

실제 원답과 시간: [재시험 로그](../eval/inquiry_grounding_retest_results.json). 이 5건으로 전체 질문 성능을 추정하지 않는다.

## 다음 구현 순서

1. **계산 계약 확장**: 현재 상태 계산뿐 아니라 목표 물리량·고정 조건을 구조화하고 역산·변경 전후를 계산한다. 단위, 부호, 정의역, 가정을 도구가 반환한다. 문장별 정답을 하드코딩하지 않는다.
2. **근거 분리**: 관련 개념·적용 식·현재 설정·계산 결과만 작성기에 전달한다. 질문과 무관한 문서 전체 전달을 줄이되 공식의 성립 조건과 출처는 보존한다.
3. **내용 검수**: 계산으로 확인 가능한 수치와 방향은 도구 결과와 대조한다. 형식 통과와 사실 확인을 별도로 표시한다. LLM 검수만으로 사실을 보증하지 않는다.
4. **모델 비교**: 같은 입력·같은 근거로 모델별 정확도, 첫 응답 시간, 완료 시간을 기록한다. 유료 모델 실험은 별도로 실행하고 비용도 기록한다.
5. **확장 평가**: 기존 53건에 설정 변경·경계값·정보 부족·다른 표현을 추가해 오답률과 불필요한 답변 거부를 함께 평가한다. 수치 문제는 허용오차로, 개념 문제는 검토 기준으로 판단한다.

핵심은 에이전트 수를 늘리는 것이 아니라 **조회 → 계산 → 설명 → 내용 대조**의 책임과 근거를 분명히 하는 것이다.
