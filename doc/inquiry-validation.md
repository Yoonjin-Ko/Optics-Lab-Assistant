## 실제 SSE API 확인

사용자 서버와 분리한 최신 코드 서버에서 HTTP SSE도 확인했습니다. 마이켈슨 목표 이동량과 카메라 상 거리 두 질문 모두 `FinalAnswer`와 `[DONE]`이 전달됐습니다. [SSE 원답·시간 기록](../eval/inquiry_sse_results.json). 이는 계산 도구 경로 확인이며 자연어 답변 내용 검증을 대신하지 않습니다.

## 재실행

```bash
LANGSMITH_TRACING=false LANGCHAIN_TRACING_V2=false .venv/bin/python eval/inquiry_live_eval.py --output /tmp/inquiry-results.json
```

기본 모델은 `qwen3:8b`이며 로컬 Ollama가 실행 중이어야 합니다. 다른 모델 비교는 `--quality-model`로 지정합니다. 보고서의 내용 판정은 원답을 읽고 기준식·설정과 대조한 수동 검토이며, 문자열 일치 테스트나 LLM 자동 채점이 아닙니다.
