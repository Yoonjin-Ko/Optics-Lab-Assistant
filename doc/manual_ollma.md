# Ollama 모드 실행 가이드

OpenAI 키 없이 로컬 모델로 설명·점검 답변을 생성합니다. 별도로 Tavily 검색을 켜면 검색 요청은 외부 API로 전송됩니다.

## 준비와 실행

프로젝트 루트에서 실행합니다.

```bash
bash sh/setup_venv.sh
# .env가 없을 때만 복사
cp .env.example .env
bash sh/setup_ollama.sh
```

이미 `.env`가 있다면 덮어쓰지 않습니다. 터미널 1에서 백엔드를 시작합니다.

```bash
bash sh/run_agent_ollma.sh
```

터미널 2에서 화면을 시작합니다.

```bash
bash sh/run_frontend.sh
```

**http://localhost:8600**에 접속합니다. 종료는 각 터미널에서 `Ctrl+C`입니다.

## 모델과 검색

실행 스크립트는 일반 대화용 모델과 답변 작성용 모델을 구분합니다. 실제 모델명은 시작 로그에서 확인합니다. 로컬 응답 속도는 모델 크기와 메모리·GPU 환경에 따라 달라집니다.

Tavily를 쓰려면 `.env`의 `TAVILY_API_KEY`를 채우고 백엔드를 재시작합니다. 기본 정의와 지원되는 공식 계산에는 검색하지 않습니다. 필요한 질문에 ‘문헌 찾아줘’ 또는 ‘출처 검색해줘’를 붙일 수 있습니다.

## 확인 순서

1. ‘편광이 뭐야?’로 일반 설명을 확인합니다.
2. ‘532 nm 광자의 에너지 계산해줘’로 MCP 계산을 확인합니다.
3. 실험의 슬라이더를 바꾸고 ‘현재 조건을 설명해줘’로 첨부 조건을 확인합니다.
4. 키를 설정했다면 ‘우라늄 페르미 준위 문헌 찾아줘’로 검색 상태와 출처를 확인합니다.

fake 모드는 실제 모델의 설명 품질을 검증하는 용도가 아닙니다. 설치 문제는 모델 준비 로그와 백엔드 터미널에서 확인합니다.
