# OpenAI 모드 실행 가이드

## 준비

프로젝트 루트에서 실행합니다.

```bash
bash sh/setup_venv.sh
```

`.env`가 없을 때만 `.env.example`을 복사합니다.

```bash
cp .env.example .env
```

`.env`의 `OPENAI_API_KEY`에 키를 입력합니다. 외부 자료 검색도 사용하려면 `TAVILY_API_KEY`를 입력합니다. API 사용료는 각 서비스 계정에 적용됩니다.

## 실행

터미널 1:

```bash
bash sh/run_agent_openai.sh
```

안내된 API 사용 확인을 마치고 서버가 실행되면 터미널 2에서 실행합니다.

```bash
bash sh/run_frontend.sh
```

**http://localhost:8600**에 접속합니다. 종료는 각 터미널에서 `Ctrl+C`입니다. `.env`나 백엔드 코드를 바꾸면 백엔드를 재시작합니다.

## 사용

1. 좌측에서 실험을 선택하고 옆 조절 장치로 값을 바꿉니다.
2. 이론·공식 또는 유의사항을 펼쳐 확인합니다.
3. 옆 채팅창에 질문합니다. 전송 시 현재 가상 실험 조건이 함께 전달됩니다.

| 질문 | 처리 |
| --- | --- |
| 산란이 뭐야? | 짧은 개념 설명 |
| 마이켈슨에서 빛은 보이는데 무늬가 안 보여요 | 관련 문서로 확인 순서 안내 |
| 532 nm 광자의 에너지를 계산해줘 | MCP 공식 계산 |
| 우라늄의 페르미 준위 관련 문헌 찾아줘 | Tavily 검색 자료를 참고한 설명 |

문서 페이지는 AI 호출 없이 열립니다. ‘조건·결과를 채팅에 넣기’는 입력창만 채우며 자동 전송하지 않습니다. ‘중지’로 응답 표시를 멈춘 뒤 새 질문을 보낼 수 있습니다.

## 문제 확인

- **8100 응답 없음:** 백엔드 터미널의 오류부터 확인합니다.
- **키 인증 오류:** `.env`의 해당 키를 확인하고 재시작합니다. 키를 로그나 저장소에 붙이지 않습니다.
- **검색 미설정·실패:** Tavily 키·사용량·네트워크를 확인합니다. 검색 없이 답한 내용을 검색으로 검증된 사실로 취급하지 않습니다.
- **오래된 화면:** 브라우저를 새로고침합니다. 새로고침하면 UI의 실험 설정은 초기화됩니다.
