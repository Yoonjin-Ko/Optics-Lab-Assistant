# 실험별 현장 조절

오른쪽 **현장 조절**을 바꾸면 검출 화면과 수치가 변합니다. ‘일부러 어긋나게 하기’로 시작하고 변수를 하나씩 조절합니다. 현재 조절값은 채팅 전송 시 자동 첨부합니다. 조절 자체로 AI를 호출하지 않습니다.

| 실험 | 직접 조절 | 확인할 변화 |
| --- | --- | --- |
| 마이켈슨 | 귀환빔 X/Y 위치, M₂ 각도, 두 빔 반경, 상대 광량 | 광점 분리·겹침, 합성 영역의 간섭 |
| 편광판 | 투과축 영점 오차, 교차 누설 | 눈금 90°와 실제 소광 위치의 차이 |
| 볼록렌즈·오목거울 | 스크린 위치, 유효 구경 | 실상면에서 벗어날 때 흐림 |
| 오목렌즈·볼록거울 | 눈의 거리·광축 이탈·유효 구경 | 허상의 각크기와 관찰 가능 범위 |
| 단일슬릿 | 빔 중심, 입사 조향각, 배경광 | 슬릿 통과 광량, 무늬 중심, 배경 |
| XRD | 검출각 영점, 시료 높이, 각도 수용폭 | 반사 위치 오차와 검출각 일치도 |
| s/p·전반사 | 입사각 영점, p축에서 벗어난 편광축 | 실제 입사각, 남는 s 성분의 반사 |
| 프리즘 | 기준 배치 대비 회전, 스크린 수직 보정 | 장치도의 입사·굴절·출사 경로, 잡히는 스펙트럼 |

| 현미경 | 시료 상하 미동 | 고정 중간상면에서의 흐림 |

## 두 빔 정렬 순서

1. **두 귀환빔 위치 확인**에서 M₁(청록)·M₂(주황)를 구분합니다. 색은 경로 표시이며 실제 서로 다른 파장의 광원이 아닙니다.
2. 주황색 중심을 끌거나 방향키, 위치 보정 X/Y로 두 중심을 맞춥니다. 위치 보정은 조향 거울쌍의 출력 효과를 뜻합니다.
3. M₂의 각도 X/Y도 조절합니다. 반사각 변화가 거울 회전의 두 배이므로 유효 전파 거리 1 m에서 빔 중심도 이동합니다. 위치와 각도는 서로 다른 조절입니다.
4. 빔 폭과 광량을 맞추고 **합성 간섭 관찰**로 전환합니다. 중심이 같아도 폭·광량·각도가 다르면 간섭 분포가 달라집니다.
5. 완전히 평행한 작은 빔은 거의 균일하게 밝을 수 있습니다. 중심을 유지하며 M₂를 0.05–0.2 mrad 정도 미세 기울이면 공간 띠를 관찰할 수 있습니다.

## 사용한 모델과 한계

- Gaussian 빔 세기 `I∝exp(−2r²/w²)`와 두 전기장 합성으로 간섭 화면을 계산합니다. 표시한 위치·빔 폭 겹침 지표는 각도·광량을 제외한 정규화 공간 포락선 적분입니다. 간섭 화면에는 각도에 따른 위상과 유한 픽셀 평균을 반영합니다. [Gaussian beams, RP Photonics](https://www.rp-photonics.com/gaussian_beams.html)의 빔 정의를 사용한 자체 학습 구현입니다.
- 흐림 원은 근축 광선 원뿔의 `D×|1−z/v|`로 계산합니다. 화면 표식과 흐림은 확대 축척이며 수차·회절 PSF는 아닙니다. 실상·허상은 [OpenStax §2.4](https://openstax.org/books/university-physics-volume-3/pages/2-4-thin-lenses)의 부호와 구분을 따릅니다.
- XRD 높이 오차는 Bragg–Brentano 평판 배치에서 `Δ(2θ)=−2h cosθ/R`(라디안), `R=200 mm`로 가정합니다. [IUCr Rietveld refinement guidelines, Eq. (3)](https://journals.iucr.org/j/issues/1999/01/00/gl0561/). 각도 일치도의 Gaussian 수용폭은 자체 입력이며 실제 회절 강도 데이터가 아닙니다.
- 현미경 미동은 대물렌즈·튜브렌즈의 근축 광선 전달로 상면 이동을 계산합니다. 고 NA 수차·벡터 회절을 예측하지 않습니다.
- 흡수계수는 **가상 입력값**입니다. 밴드갭에서 실제 물질의 흡수율을 추정하지 않습니다. 금속은 최대 운동에너지 전자의 도달 조건만 보여주며 실제 광전류 곡선을 재현하지 않습니다.

기존 이상적 이론 그래프는 비교용으로 유지합니다. 현장 조절 검출 화면은 별도로 표시하며 실제 측정값·제조사 장비 디지털 트윈으로 표현하지 않습니다. AI가 조절 상태를 올바르게 설명하는지는 별도 내용 검증 대상입니다.

## 확인

`node tests/test_practical.cjs`는 빔 정렬·기울기 보상, 초점, 허상 관찰, 슬릿 광량, 편광 누설, 시료 높이, 흡수·저지 전압과 조절 범위 끝값을 검사합니다. UI에서도 14종 메뉴의 조절값 변화, 검출 화면 변화, 키보드 조작, 채팅 첨부를 확인했습니다.

## 간섭무늬 관찰 수정 (2026-10-22)

간섭계 기본 모드는 합성 간섭이다. `원형 간섭무늬 보기`는 기울기 0·같은 빔 중심·초기 팔 길이 차이 20µm로, `기울어진 간섭무늬 보기`는 기준 팔 차이 0·작은 M₂ 기울기와 위치 보정으로 관찰 조건을 준비한다. 실제 장치의 자동 정렬 기능을 뜻하지 않는다. 두 빔 위치 확인은 별도 모드로 유지한다.

간섭 관측은 f=10mm 관측 렌즈·화면 ±4mm 확대, 정렬 확인은 ±12mm이다. 큰 정렬 범위와 좁은 빔에 f=100mm의 위상을 함께 표시하던 조건은 빔 내부 위상 변화가 작아 무늬가 잘 보이지 않았다. 현재 합성 위상은 `2πN + k(2αx x+2αy y) + 4π(기준 팔 차이+Δx)/λ·(cosθ−1)`이며 `θ=atan(r/10mm)`이다. 화면 밝기는 관찰을 위한 제곱근 감마를 적용하며 정량 세기 그래프와 구분한다.

위상·팔 길이 차이·기울기를 바꿀 때 검출 이미지가 달라지는 검사와 UI의 ¼주기·관찰 모드 전환을 확인했다. 기울기를 위치 보정으로 상쇄해도 위상은 변해야 하므로 이미지 캐시 키에 기울기를 별도로 포함했다. 하단 이상적 단면 그래프는 기존 f=100mm·±30mm 모델이며 확대 관측 화면의 단면과 다르다.

## 단일·이중슬릿 검출 화면 (2026-10-22)

슬릿 메뉴에서 단일/이중슬릿을 선택한다. 스크린을 정면에서 본 밝고 어두운 세로띠를 위에, 이상적 상대 세기 그래프를 아래에 표시한다. 단일슬릿은 sinc² 회절, 이중슬릿은 유한 폭 회절 포락선과 cos² 간섭을 함께 계산한다. 슬릿 중심 간격 d는 폭 a보다 커야 하며 UI에서 이를 유지한다.

- 폭 a는 포락선 전체 폭 W≈2λL/a를 정한다.
- 중심 간격 d는 촘촘한 간섭무늬 간격 Δy≈λL/d를 정한다.
- 검출 화면의 빔 조향은 중심 이동, 빔 이탈은 각 슬릿의 조명량·대비, 배경광은 암부 밝기에 반영한다.
- 이상 그래프는 균일 조명·중심 정렬 기준이다. 현장 검출 화면은 조명량과 배경을 포함하며 두 화면의 정규화는 다르다.
- 스크린 세로 방향은 무한히 긴 슬릿의 이상화이다. 실제 사진·검출기 응답이나 근거리 Fresnel 회절을 재현하는 것은 아니다. 화면 감마는 제곱근으로 약한 띠를 잘 보이게 한다.

공식: [OpenStax 4.3 Double-Slit Diffraction](https://openstax.org/books/university-physics-volume-3/pages/4-3-double-slit-diffraction).

## 두 거울까지의 거리 조절

간섭계는 빔스플리터에서 M₁·M₂까지의 기준 편도 거리를 각각 mm로 조절한다. 현재 M₂ 거리는 L₂+Δx, 편도 차이는 L₂−L₁+Δx, 공기 중 왕복 광로차는 약 2(L₂−L₁+Δx)로 자동 표시한다. 기본 100 mm·100.02 mm에서는 편도 차이 20 µm·왕복 광로차 40 µm이다. 두 거리 변경을 중심 위상과 원형 무늬 곡률에 함께 반영하며, 별도의 미동 주기 카운터는 Δx 변화만 센다.
